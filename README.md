# Lel.tar Backend

Backend server for the school project game **[Lel.tar](https://github.com/LohinSys/LelTarGame)**, made using **ASP.NET 8.0** and **Visual Studio 2026**.

## Role Index

|	| Role name	| Description |
|---| --------- | ----------- |
|👑	| Admin		| All priviliges |
|🔨	| Moderator	| Priviliges to manage users |
|👤	| User		| Default role given to all users |
|❌	| Banned	| Banned users who have no priviliges whatsoever |
